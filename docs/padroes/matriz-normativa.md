# Matriz normativa

## Status

**REGRA APROVADA.** Toda referência normativa deve ser verificada e registrada
antes de sustentar análise ou conclusão. Os anos e versões encontrados nos
laudos de referência não foram consolidados como verdade definitiva.

## Campos obrigatórios

| Campo | Regra |
|---|---|
| Entidade | Identificar a entidade emissora |
| Número | Registrar exatamente após conferência |
| Título | Registrar o título oficial conferido |
| Edição/ano | Registrar a edição aplicável ao caso |
| Aplicabilidade | Explicar a relação com o objeto ou a manifestação |
| Status de verificação | Usar valor controlado desta matriz |
| Evidência de verificação | Indicar fonte consultada pelo perito |
| Manifestações relacionadas | Relacionar `PAT-NNN`, quando aplicável |

## Status de verificação

- `NÃO VERIFICADA`
- `EM VERIFICAÇÃO`
- `VERIFICADA`
- `NÃO APLICÁVEL`
- `SUBSTITUÍDA/REVOGADA` — somente após confirmação.

## Regra para divergência

Quando houver edição divergente, ausente ou não confirmada, usar:

`[VALIDAÇÃO DO PERITO: confirmar edição normativa aplicável]`

Não inventar número de item, redação, título, edição ou vigência.

## Aplicação no laudo

- Concentrar conceitos, classificações e critérios gerais no capítulo 2.
- Citar em cada `PAT-NNN` apenas a norma efetivamente necessária.
- Não repetir longas definições em todas as manifestações.
- Não listar norma na bibliografia apenas porque constava em laudo anterior.
- Não usar norma posterior aos fatos sem análise expressa de aplicabilidade.
- Preservar distinção entre requisito técnico, prazo de garantia e diagnóstico
  causal.
