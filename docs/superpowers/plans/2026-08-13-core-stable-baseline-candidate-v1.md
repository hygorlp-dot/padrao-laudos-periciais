# Core Stable Baseline Candidate V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Produce a deterministic, observational inventory and fingerprint of the Core Pericial at `8530584c82061fb35018afd6638032ba8798b105`.

**Architecture:** A stdlib-only analyzer reads tracked blobs from an explicit Git commit, composes existing invariant/boundary/fixture/schema registries, performs static AST analysis without importing Core modules, and emits canonical JSON plus a detached SHA-256. Documentation interprets the generated evidence without changing runtime contracts.

**Tech Stack:** Python stdlib (`ast`, `hashlib`, `json`, `subprocess`), Git object database, pytest.

## Global Constraints

- Observational only; no Core refactor or semantic/schema/product change.
- Read only committed Git blobs; exclude private, untracked, temporary and self-referential output files.
- Semantic payload has sorted deterministic data and no timestamp, duration, CI ID or absolute path.
- No new dependency.
