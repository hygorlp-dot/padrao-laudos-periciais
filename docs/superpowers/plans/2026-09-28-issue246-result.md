## Causal result

The report summary button and command required a bound approved pathology.
A draft with effective technical findings but no PAT could not use the table.
The command now captures only findings belonging to the current APPROVE or
MODIFY decision, after checking workspace, snapshot identity, revision, digest
and stale state. Canonical save independently compares every technical row with
the effective source. Scope and proposition are presented as **Escopo** and
**Achado técnico**. No environment, cause or classification is inferred.

The technical snapshot already preserves the proposal, evidence, method and
professional decision. Row provenance binds that snapshot revision. A material
upstream change makes the report stale; a new report version recaptures current
rows. Legacy PATHOLOGY rows still deserialize and render exactly; a table cannot
mix the two presentation meanings. No PAT gate, review or causal engine changed.
