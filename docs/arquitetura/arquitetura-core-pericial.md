# Arquitetura do Core Pericial

## Regra aprovada

O Core Pericial é a autoridade para contratos, evidências, classificações,
gates e resultados técnicos. Agentes, interfaces e integrações apenas propõem,
orquestram ou apresentam dados; não promovem proposta a decisão.

Mudanças no Core exigem Issue, TDD, `verify_core --full`, revisão independente
e os gates adicionais determinados pelo risco.
